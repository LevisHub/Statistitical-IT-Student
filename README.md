1.	INTRODUCTION TO INFORMATION TECHNOLOGY AND COMPUTERS.
Meaning of Information Technology
•	Information Technology(IT) refers to the use of computers, software, networking devices and other electronic systems to store, retrieve, transmit and process data into meaningful information.
Data and Information
•	Data – raw and unprocessed facts that once processed they give information.
•	Information – processed, organized and meaningful data.
Computer
•	A computer is an integrated system whose components collaborate to execute complex analytical workflows.
Characteristics of a Computer 
•	Speed – can process millions of operations per second.
•	Accuracy – very low error margin.
•	Automation – work with very low human intervention.
•	Storage – large capacity for data retention.
•	Diligence – no fatigue or loss of concentration.
•	Versatility – can handle multiple tasks.
•	Consistency – same output for same input.

Types of Computers 
A.	By Size.
•	Supercomputers- extremely powerful; used in weather forecasting and scientific operations.
•	Mainframe computers- used in banks, government, airlines.
•	Minicomputers- mid-range; used in organizations.
•	Microcomputers- personal computers.
B.	By Purpose.
•	General purpose- for many tasks (PCs).
•	Special purpose- designed for one task (ATMs, embedded systems).
C.	By Data Handling.
•	Analog computers- continuous data.
•	Digital computers- discrete data.
•	Hybrid computers- combination of both continuous and discrete data.

2.	FUNDAMENTALS OF COMPUTER OPERATIONS.
Meaning.
•	Computer operations refer to the basic processes, components and activities that allow a computer system to function and perform tasks.
•	These fundamentals are usually grouped into input, processing, output and storage.

1.	Input Operations.
•	Input operations involve entering data and instructions into the computer.
•	Common input devices include:
1.	Keyboard – typing data.
2.	Mouse/Touchpad – pointing and selecting.
3.	Scanner – converting physical documents into digital form.
4.	Microphone – voice input.
5.	Camera – capturing images/video.
•	Input is the first step of any computing task.
2.	Processing Operations.
•	This is the transformation of raw data into useful information.
•	It is performed by the Central Processing Unit (CPU) which has two main parts:
1.Arithmetic Logic Unit(ALU) - handles arithmetic and logical operations.
2. Control Unit(CU) – directs and coordinates all system activities.
•	Processing includes:
-Executing instructions.
-Performing calculations.
-Managing system resources.

3. Output Operations.
•	Output is the production of processed information in a form that humans or other systems can use.
•	Examples of output devices include:
1.Monitor
2.Printer
3.Speakers
4.Projector
•	Output can be soft or hard copy.

4.Storage Operations.
•	They involve saving data and programs for future use.
•	Storage is of two types:
A.	Primary Storage(Main Memory).
a.)	Random Acces Memory (RAM) – temporary/volatile.
b.)	Read Only Memory (ROM) – permanent.


B.	Secondary Storage.
•	Long-term storage devices such as:
-Hard Disk Drive (HDD)
-Solid State Drive (SSD)
-USB Flash Drive
-Memory Card
-Cloud Storage

Operating System Role.
•	Operating System (OS) manages:
-Hardware
-Files and data
-System resources
-Applications
-User interface 
•	Examples include: Windows, Linux, macOS, Android.

4.	COMPUTER SOFTWARE BASICS.
•	Computer software refers to the set of programs, instructions or data that tell a computer how to operate and perform tasks.
•	Software is intangible but it controls how hardware works.

Types of software.
•	Software is generally categorized into system software and application software with additional specialized categories.

A.	System Software.
•	This manages and operates computer hardware and provides a platform for application software.

1.	Operating System.
•	The OS is the core system software that manages:
-	Hardware resources 
-	File management
-	Process management 
-	Security and user accounts
-	Networking 

2.	Utility Programs.
•	Utilities help maintain, optimize and maintain the computer.
•	Examples:
-	Antivirus software 
-	Disk cleanup tools
-	Backup tools
-	File compression (WinRAR, 7-Zip)

3.	Device Drivers.

-	Printer drivers
-	Graphics drivers

5.	DATA AND DATA FILES.
Data.
•	Data refers to raw, unorganized facts that have no direct meaning until processed.
•	Examples include numbers, symbols, texts, images, audio and video.

Characteristics of data.
•	Raw – not yet interpreted or analyzed.
•	Unprocessed – has not gone through any transformation.
•	Context-dependent – meaningless without an environment or purpose.
•	Can be structured or unstructured.

Types of data.
•	Qualitative data – descriptive, non-numerical e.g. colour, gender.
•	Quantitative data – numerical e.g. height, age.
•	Discrete data – counted, whole numbers. e.g. number of students.
•	Continuous data – measured, can take any value. e.g. temperature, weight.
•	Primary data – collected first-hand.
•	Secondary data – collected by others.

Information.
•	Information is processed data that is useful and meaningful for decision-making.

Data representation in computers.
•	Computers represent data using binary(0s and 1s).
•	Basic units:
-	Bit – smallest unit (0 or 1)
-	Nibble – 4 bits
-	Byte – 8 bits 
-	Kilobyte(KB) – 1024 bytes
-	Megabyte(MB) – 1024 kilobytes
-	Gigabyte(GB) – 1024 megabytes
-	Terabyte(TB) – 1024 gigabytes 

Data Files.
•	A data file is a named collection of related data stored permanently on secondary storage devices such as hard disks or flash drives.

Types of data files.
-	Text files
-	Binary files 
-	Database files 
-	Multimedia files 
-	Document files
